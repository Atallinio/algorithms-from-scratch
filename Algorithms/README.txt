Problem explanations

Problem 1 (Radix Sort):
Implement Radix Sort using Counting Sort as the underlying stable sort in C. Must handle 10-digit integers (d=10) in base 10 (k=10). Array length n ≤ max(A[i]).

Problem 2 (Propositional Satisfiability):
Determine if a 2-SAT formula has a satisfying assignment. Input is list of literal pairs like [[1,-2],[2,1], where positive=unnegated, negative=negated. Return True/False.

Problem 3 (Linked List Quicksort):
Implement Quicksort on singly linked list using Lomuto partitioning (last element as pivot). Must rearrange nodes in-place to ascending order.

Problem 4 (Linked List to Balanced BST):
Convert singly linked list to height-balanced binary search tree. Input size: 0-20,000 nodes with values ±100,000. Must maintain balance.

Problem 5 (Robot Tournament):
Simulate robot tournament where two highest HP robots battle each round. Equal HP: both destroyed. Unequal HP: subtract smaller from larger. Return last robot's HP or 0.
